Guida rapida alle fonti
Sotto ogni social trovi dove recuperare i dati e quali file mettere nella cartella settimanale.
YouTube
Dove trovare i dati
YouTube Studio → Analytics → Panoramica / Contenuto
File nella cartella
yt_overview.csvyt_contenuto.csv
Dati chiave
Iscritti, visualizzazioni, CTR, video pubblicati.
Instagram
Dove trovare i dati
Meta Business Suite → Como TV IG → Insights → Contenuto
File nella cartella
ig_feed.csvig_storie.csv
Dati chiave
Reach, views, interazioni, stories, clic link.
TikTok
Dove trovare i dati
TikTok Studio → Analytics
File nella cartella
tiktok_analytics.csv
Dati chiave
Views, like, commenti, condivisioni, profilo.
Facebook
Dove trovare i dati
Meta Business Suite → Como TV FB → Insights → Contenuto
File nella cartella
fb_posts.csv
Dati chiave
Reach, views, reazioni, commenti, condivisioni.
LinkedIn
Dove trovare i dati
LinkedIn Page Admin → Analytics → Aggiornamenti
File nella cartella
linkedin_updates.csv
Dati chiave
Impressioni, clic, engagement, follower acquisiti.
